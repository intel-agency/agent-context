# Reference

This section is the lookup shelf for the repository. It catalogues the configuration files that control tooling, the structured data models that flow through the skill scripts, and the external dependencies that must be present for everything to run.

- [Configuration](configuration.md) - every config file in the repo, what it controls, and its key parameters
- [Data models](data-models.md) - the canonical node schema, label taxonomy, issue body templates, and app stack definitions
- [Dependencies](dependencies.md) - runtime tools, PowerShell modules, npm packages, MCP servers, and model providers with versions

For the architecture that ties these pieces together, see [Architecture](../overview/architecture.md). For the terms used across these pages, see [Glossary](../overview/glossary.md).
